## Three Security Fixes

| Issue | Type | Fix | Impact |
|-------|------|-----|--------|
| **Weak Password Hashing** | Medium | MD5 → SHA256 | Stronger password security |
| **Cross-Site Scripting (XSS)** | High | Add output escaping | Prevents script injection |
| **Path Traversal** | Medium | Strict validation | Blocks directory traversal |

## How to Use This Package

### For BellaBook Upstream PR

```bash
# 1. Clone the official repo
git clone https://github.com/jemjabella/BellaBook.git
cd BellaBook
git checkout -b security-improvements

# 2. Apply the patch
git apply /path/to/bellabook-security.patch

# 3. Verify and commit
git diff  # Review changes
git status
git commit -m "Security improvements: SHA256, XSS protection, path traversal fixes"

# 4. Push and create PR
git push origin security-improvements
# Then create PR via GitHub UI
```

### For OpenLetter Fork

```bash
cd /path/to/your/openletter/fork
git apply /path/to/bellabook-security.patch
git commit -m "Security improvements"
git push origin security-improvements
```
